# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-14

### Added
- AMD shader cache cleaner.
- Network repair and optimization utility.
- OneDrive removal utility.
- Windows cleanup utility with automatic/manual/preview modes.
- WinSxS maintenance and repair utility.
- Read-only cleanliness scan with HTML/CSV reporting.
- Windows 11 context-menu switcher.

### Changed
- Standardized public repository naming and documentation.
- Removed legacy internal project-name references from comments and temporary filenames.
- Context-menu utility no longer requests unnecessary administrator privileges.
